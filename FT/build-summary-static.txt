- এই বিল্ড TEST মোডে: অ্যাপে কোনো ইন্টিগ্রিটি/সাইন চেক নেই, যেকোনো ফোনে চলবে।
- Play Store-এ দেওয়ার আগে SECURITY_MODE=PLAY_STORE দিয়ে আবার বিল্ড করুন এবং Play Console থেকে SHA-256 (App signing) দিন।
- সোর্স কোড PCK এনক্রিপশন + বাইনারি টোকেনে সুরক্ষিত: এটা বাধা, অভেদ্য নয়।

==== DIFFERENCES vs HTML (1:1 port, nearest equivalent used) ====
1. Backdrop blur (glass) -> semi-transparent cards + soft shadow + blurred-looking orbs (no real backdrop-filter in Compatibility renderer).
2. CSS gradients/gloss -> rounded gradient shader (same 3 stops/angles); text gradient on title simplified to accent colour.
3. Camera: browser getUserMedia -> Godot CameraServer (Camera2 feed), frames decoded by a pure-GDScript QR decoder (HTML used a JS lib). Decode speed/quality may differ on low-end phones.
4. Torch/flash: not available on the rear camera in Godot (toast shown). Front camera uses a white screen light as in the HTML.
5. Gallery pick/Save PNG: Android file dialog (SAF) instead of <input type=file>/download link. Share: Android share intent.
6. Swipe between Create panes (HTML scroll-snap) not ported; Edit/Back button switches panes. Android Back key goes Result -> Edit -> Create tab -> exit.
7. QR generator: own pure-GDScript encoder (byte mode, same smallest-version/mask rules as qrcode-generator). Verified against OpenCV.
8. Ads: AppMint browser bridge replaced by native AdMob (banner on top, interstitial pacing kept: 1st QR, then every 3rd). Retry uses exponential back-off 5-60 s.
9. Fonts: Baloo Da 2 bundled (Bengali shaping needs TextServerAdvanced, default in Godot builds).
10. Local data: localStorage -> encrypted file user://ft_state.sav.
11. Hidden diagnostics (tap logo 5x) kept.
